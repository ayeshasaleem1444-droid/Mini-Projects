# Mini Projects

A collection of small HTML, CSS and JavaScript projects — each one in its own folder, each one runnable by opening its `index.html` in a browser.

| Project | What it does |
|---|---|
| `character counter` | Live character counter for typed text |
| `css_components` | Practice CSS components |
| `dynamic-profile-card` | Fill in a form and it generates a profile card — name, profession, bio and photo |
| `quiz-game` | Interactive quiz game |
| `reg form` | Registration form |
| `safex-landing-page` | Landing page built for SafeX Solutions |
| `to-do-list app` | To-do list with localStorage saving |
