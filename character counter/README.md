Character Counter:
A simple, lightweight web application that tracks character input in real-time. It features a 10-character limit indicator that changes color to warn the user when they have exceeded the allowed length.
Features:
Real-time Tracking: Updates the character count instantly as you type.
Character Limit: Formatted around a strict 10-character boundary.
Visual Alerts: The counter dynamically switches from **black** to **red** if the text exceeds 10 characters, letting the user know they are over the limit.
Technologies Used:
HTML5: For the input structure and layout.
JavaScript (ES6): For DOM manipulation and real-time event handling.
